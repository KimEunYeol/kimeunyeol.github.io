소개

데이터를 모으고 다듬어 서비스에 연결하는 일을 해왔습니다. 공공·제조 분야에서 데이터 파이프라인과 AI 운영 백엔드를 만들고, 운영 중 생기는 지연과 오류를 살피며 경험을 쌓았습니다.

함께 일할 때는 상대가 겪는 어려움을 먼저 듣고, 풀어야 할 문제를 같이 정리하려고 합니다.

개발환경 구축안 작성 · CI/CD 장애 대응 · Airflow · Docker · Python

데이터 레이크 고도화 참여 · Airflow · AWS Glue · PySpark
