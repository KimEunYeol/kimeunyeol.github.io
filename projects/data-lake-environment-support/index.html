데이터레이크 개발환경 검토·기술 지원

운영 구성을 축소한 Airflow 개발환경 구축안을 작성하고, GitLab CI/CD·Runner 장애에 긴급 대응했습니다.

2025.12–2026.01
구분
제조업 고객사 프로젝트 참여

개발환경 구축안 작성 · CI/CD 장애 대응

프로젝트 소개

데이터레이크의 개발환경 구성을 검토하고 구축안을 작성했습니다. 후속 지원에서는 GitLab 파이프라인 실패와 Merge·Runner 오류로 개발·배포가 막힌 상황에 대응했습니다.

맡은 일

  • 운영 구성을 축소한 Airflow 개발환경 구축안을 작성하고 요청사항을 반영해 보완했습니다.
  • Python·Docker·PostgreSQL 구성과 시스템·DAG 로그 관리 항목을 검토했습니다.
  • GitLab 프로젝트 설정, CI/CD 설정 파일과 Runner 상태·로그를 점검했습니다.
  • 캐시 정리와 GitLab·Runner 재기동 후 개발·배포 프로세스의 정상 동작을 확인했습니다.

구현·검토 내용

운영 환경을 기준으로 개발계 검토

별도의 구성을 새로 잡기보다 운영 환경을 축소하는 방향으로 개발계 구축안을 작성했습니다. 설치 항목과 로그 관리 조건을 함께 검토했습니다.

설정·Runner·로그를 나눠 확인

파이프라인 실패와 Merge·Runner 오류를 확인하고 설정, 실행 상태와 로그를 차례로 점검했습니다. 조치 뒤 실제 동작을 확인해 개발·배포 재개 여부를 살폈습니다.

사용 기술

  • Airflow
  • Docker
  • Python
  • PostgreSQL
  • GitLab CI/CD
  • GitLab Runner

진행 상태

개발환경 구축안 작성과 GitLab CI/CD 장애 조치·동작 확인을 수행했습니다.
