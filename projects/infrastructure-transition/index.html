분석 인프라 전환 검토

Cloud의 S3 적재 흐름을 Private IDC로 옮길 때 필요한 저장 경로와 운영 설정을 검토했습니다.

기간
2025.01–2025.07
구분
제조업 고객사 프로젝트 참여
역할
응용 소프트웨어 개발 참여

프로젝트 소개

분석 인프라를 통합·전환하는 프로젝트에 참여했습니다. S3에 쌓던 CSV를 공유 스토리지로 옮길 때 달라지는 파일 경로와 실행 환경을 비교했습니다.

맡은 일

  • 기존 S3 적재 경로와 Private IDC 공유 스토리지의 목표 경로를 비교했습니다.
  • Airflow 메타데이터·로그 저장 위치와 ETL 작업 분할 방안을 검토했습니다.
  • 파일 형식 변환과 카탈로그 연계에서 바뀌어야 할 항목을 정리했습니다.

구현·검토 내용

저장 경로와 실행 환경을 함께 검토

파일 경로뿐 아니라 스케줄러의 접근 방식, 메타데이터 저장 위치와 운영 로그까지 비교했습니다.

후속 작업 정리

파일 형식 변환, 카탈로그 연계와 작업 분할을 후속 설계에서 확인할 항목으로 정리했습니다.

사용 기술

  • Airflow
  • SQL
  • CSV
  • S3
  • 공유 스토리지

진행 상태

기존 환경과 목표 환경을 비교하고 전환 방안을 검토했습니다. 여기서는 검토 단계에서 맡은 업무를 소개합니다.
