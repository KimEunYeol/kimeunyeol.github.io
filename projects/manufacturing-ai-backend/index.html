제조 AI 운영 백엔드 구축·확장

제조 AI 서비스의 외부 데이터 수집과 연계를 담당하고, 모델별 전처리·추론 서비스 확장에 참여했습니다.

기간
2021–2023, 단계별 참여
구분
제조업 고객사 프로젝트 참여
역할
백엔드 개발, 외부 데이터 연계

프로젝트 소개

제조 현장의 분석 모델을 업무 서비스에 연결하는 프로젝트였습니다. 추론에 필요한 데이터를 수집하고 모델별 처리 서비스에 전달하는 백엔드를 개발했습니다.

맡은 일

  • 외부 SOAP 웹 서비스에서 원천 데이터를 수집하고 백엔드에 연결했습니다.
  • 수집 지연이 발생한 구간의 로그와 Kafka Consumer 설정을 점검했습니다.
  • 모델별 전처리·추론 컨테이너를 추가하는 작업과 서비스 확장·분리 작업에 참여했습니다.

구현·검토 내용

모델별 처리 분리

전처리와 추론을 모델별 컨테이너로 나누는 구조를 사용했습니다. 공통 데이터 연계와 모델별 처리 부분을 구분해 확장 작업을 진행했습니다.

수집부터 결과 저장까지 추적

SOAP 수집, Kafka 전달, Redis의 추론용 데이터, S3 이력 저장을 차례로 확인했습니다. 지연이 발생하면 수집과 소비 구간의 로그를 나눠 살펴봤습니다.

사용 기술

  • Python
  • Docker
  • Kafka
  • Redis
  • AWS EC2
  • S3

진행 상태

2021–2023년 구축·확산·확장 단계에 참여했습니다. 외부 데이터 연계와 백엔드 개발을 담당했습니다.
