프로젝트 소개

여러 개체의 사진과 성장 기록, 관리 일정을 한곳에서 볼 수 있도록 만든 개인 프로젝트입니다. 개체를 관리하는 공간과 다른 사람에게 공유하는 공개 프로필을 나눠 구성했습니다.

맡은 일

  • 개체 정보와 사진, 날짜별 체중과 성장 기록을 관리하는 화면을 만들었습니다.
  • 피딩과 이벤트 일정을 모아 보고, 프로필에 외부 링크를 연결하는 화면을 구성했습니다.
  • 공개 프로필과 소유자용 관리 화면을 나누고, 모바일에서도 기록과 정보를 확인할 수 있도록 구현했습니다.

구현·검토 내용

개체별로 기록 모으기

개체 정보와 사진, 성장 기록을 연결했습니다. 여러 개체를 기르는 사람이 필요한 기록을 개체별로 찾아볼 수 있도록 화면을 구성했습니다.

관리 공간과 공개 프로필 분리

직접 관리하는 정보와 다른 사람에게 보여주는 프로필을 구분했습니다. 공개 프로필에서는 개체 정보와 외부 링크를 함께 볼 수 있도록 했습니다.
