프로젝트 소개

파이프라인 실행이 끝나도 데이터에 문제가 있거나 검사 근거가 빠질 수 있습니다. 실행 결과와 데이터 품질을 함께 확인할 수 있도록 사내 데이터 플랫폼을 개발하고 있습니다.

맡은 일

  • 명세, 실행, 품질 검사와 증거 이력을 나눠 아키텍처를 설계했습니다.
  • FastAPI와 SQLite로 제품 등록, 모의 실행, 검사 결과 조회와 이력 저장 기능을 만들었습니다.
  • 중복 요청, 저장 중 실패와 재시작 후 조회를 처리하고, 정상·품질 실패·증거 누락 시나리오를 검증했습니다.

구현·검토 내용

실행 상태와 품질 판정 분리

실행이 성공했더라도 검사에 실패하거나 필수 증거가 없으면 데이터를 사용 가능 상태로 바꾸지 않도록 했습니다.

로컬 환경에서 먼저 구현

운영 시스템에 연결하기 전에 가상 주문 데이터로 명세와 실행 결과, 검사와 증거가 연결되는지 확인했습니다.

사용 기술

  • Python
  • FastAPI
  • Pydantic
  • SQLite
  • Airflow
  • 파이프라인 명세

진행 상태

가상 데이터로 동작하는 로컬 MVP를 개발했습니다. 운영 DB와 Airflow 연동은 아직 진행하지 않았습니다.
