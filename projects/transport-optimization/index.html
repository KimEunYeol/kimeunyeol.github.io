프로젝트 소개

제조 공장 간 운송을 분석하고 차량 운영 방안을 비교하는 프로젝트에 참여했습니다. 실적 데이터와 업무 제약을 정리하고, 가상 데이터로 시작한 모델을 실제 운송 기록으로 테스트했습니다.

맡은 일

  • 현장대리인으로 프로젝트에 참여해 입력 데이터 요구사항과 협의 항목을 정리했습니다.
  • 차량 용량, 시간과 거리 제약, 물동량의 CBM 환산 기준을 검토하고 OR-Tools 기반 시뮬레이션을 개발했습니다.
  • 운송 실적의 시간·차량 컬럼을 점검하고 정제 데이터와 제외 데이터를 나눠 전달했습니다.
  • AS-IS와 TO-BE의 차량 수·운행 횟수·물동량을 비교하고 테스트 결과를 공유했습니다.

구현·검토 내용

목적함수와 제약조건 먼저 정리

차량 수 최소화를 목표로 두고 용량·시간·거리와 운행 조건을 나눠 검토했습니다. 모델에 넣을 필수 컬럼과 기준 정보도 함께 정리했습니다.

입력 정제와 결과 비교를 분리

정제 전 데이터와 제외 데이터를 별도로 관리했습니다. 시뮬레이션 결과에서는 물동량이 유지되는지 확인하고 차량 수와 운행 횟수를 비교했습니다.

사용 기술

  • Python
  • OR-Tools
  • Excel
  • 운송 최적화
  • 데이터 정제

진행 상태

과거 운송 실적으로 모델링과 시뮬레이션 비교 테스트를 수행했습니다.
