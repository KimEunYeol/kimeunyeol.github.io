프로젝트 소개

동아리 소개와 활동 정보를 한곳에서 볼 수 있는 웹사이트를 개인 제작했습니다. 방문자가 보는 공개 웹과 운영자용 관리 화면을 구성했습니다.

맡은 일

  • 소개, 일정, 공연, 공지와 활동 기록 화면을 만들었습니다.
  • 방문자용 공개 웹과 운영자용 관리 화면을 나눠 구성했습니다.
  • 권한과 저장 정책을 검증하기 전에는 관리 화면에서 데이터를 변경할 수 없도록 했습니다.

구현·검토 내용

공개 웹과 관리 화면 분리

방문자가 읽는 화면과 운영자가 정보를 편집하는 화면을 나눠 구성했습니다.

관리 기능은 검증 후 연결

화면 개발과 데이터 쓰기 권한을 분리했습니다. 권한·저장 정책을 확인하기 전에는 로그인, 저장과 업로드를 열지 않았습니다.

사용 기술

  • React
  • TypeScript
  • Vue
  • Vuetify

진행 상태

공개 웹과 관리 화면을 제작했습니다. 관리 로그인·저장·업로드는 권한과 저장 정책 검증이 끝날 때까지 비활성화한 상태입니다.
