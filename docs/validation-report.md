# 공개 내용 정리 검증

확인일: 2026-11-12. 프로젝트 탐색형 디자인과 문체 수정 후 배포 전 점검 결과다.

## 정리 결과

- 업무 유형으로 표기한 전문 프로젝트 4개, 기술경력 8건, 업무 기록 7편을 유지했다.
- 사내·고객사 솔루션과 회사의 고유명은 업무 유형이나 업종으로 일반화했다. 명칭이 포함된 이전 생성 경로도 제거했다.
- 개인 연락처·계정 링크와 학교·수상·연구 시연 자료를 공개 대상에서 제외했다.
- 식별 가능한 화면 이미지와 사용하지 않는 이전 테마의 소개 원문·설정·학습 글을 공개 저장소에서 제거했다.
- 이름·직무·참여 기간·역할·기술 경험과 직무 자격은 경력 설명에 필요한 항목으로 유지했다.
- 추가 요청에 따라 개인 제작은 '음악동아리'라는 일반명칭만 사용하는 별도 항목으로 반영했다. 본문·메타데이터·URL·메뉴·검색·인쇄용 경력 요약에 같은 명칭을 사용한다.

## 검증

`node --test tests/site.test.mjs`: 6개 통과.

내부 링크·앵커, 공개 필드, 검색·sitemap의 대상, 제외된 원본·이미지 경로, 삭제한 기록의 생성 페이지 잔존 방지와 HTML 출력을 확인했다. 변경 코드 구문 검사와 공백 검사도 통과했다.

현재 공개 파일과 경로에서 정리 대상 고유명·개인 식별 항목이 남지 않았는지 별도 점검했다. 검사는 Git 이력과 로컬 의존성 캐시를 제외한 현재 파일에 대한 것이다.

Chrome에서 홈을 1280px, 768px, 375px, 320px로 확인했다. 가로 넘침이 없었고, 업무·개인 분류, 기술명 검색, 검색 결과 없음, 선택 프로젝트 요약과 전체 검색이 동작했다. 모바일 메뉴와 Escape로 검색 닫기도 확인했다.

데이터 생산 통제 플랫폼, NiFi·Hive 업무 기록, 경력과 이력서를 1280px와 320px에서 확인했다. 가로 넘침이 없었고 각 페이지의 h1은 하나였다. 브라우저의 오류 로그는 없었다. 내부 링크와 앵커는 활성 공개 문서 18개, 제외 안내와 404를 포함해 자동 검사했다.

이번 수정에서는 인쇄용 HTML과 인쇄 스타일을 갱신했으며 새 PDF를 생성하거나 인쇄 결과의 페이지 수를 검증하지 않았다. JavaScript 비활성화 브라우저 검증은 재실행하지 않았다. 각 프로젝트의 실제 상세 링크는 정적 HTML에 유지하고 자동 검사했다.

## 범위

공개 파일에 대한 점검이며 원격 저장소의 과거 이력은 변경하지 않는다. 원본 증빙과 비공개 근거 자료는 공개 저장소 밖에서 보존한다. 배포 결과는 GitHub Pages와 실제 공개 URL에서 별도로 확인한다.
