# 공개 내용 기준

## 유지

포트폴리오의 이름·직무, 업무 유형, 참여 기간, 담당 역할, 사용 기술, 확인된 수행 결과를 유지한다. 전공은 학위·전공 수준만 쓰고 직무 자격은 종류만 표시한다. 사이트 자체의 주소는 문서 식별과 탐색을 위해 사용한다.

개인 제작은 사용자가 지정한 음악동아리 프로젝트만 일반명칭으로 소개한다. 고객사 기술경력과 별도 항목으로 구분하고, 고유 이름을 드러내는 URL·이미지는 사용하지 않는다.

## 제외 또는 일반화

- 사내·고객사 솔루션과 서비스의 실제 고유명. URL 경로와 검색 색인에도 넣지 않는다.
- 회사·고객사 실명. 업종이나 기관 유형으로 표기한다.
- 개인 이메일·전화·주소·생년월일, SNS·계정 링크, 학교명과 학위 취득 시기.
- 증명서 식별번호·등록번호·QR과 원본 증빙 파일.
- 승인한 일반명칭의 개인 제작 항목 외 서비스 홍보, 연구 시연·수상 세부사항, 과거 학습 글과 디자인 조사 자료.
- 공개 대상에서 제외된 내용이 남아 있는 이미지·원문·사용하지 않는 테마 설정.
- 포트폴리오 제작 과정의 대화·도구·파일 경로·검토 메모를 설명하는 본문.

## 정확성

참여 업무와 전체 프로젝트 성과를 구분한다. 검토 중인 항목을 구현 완료로 바꾸지 않는다. 가상 데이터 로컬 구현과 실제 운영 환경의 완료 상태를 구분한다. 부분 실패나 미확인 결과는 확인 범위에 남긴다.

## 적용 위치

본문, 제목과 설명 메타데이터, 모바일 탐색, 검색 색인, sitemap·feed, 인쇄용 이력서, 정적 이미지와 저장소의 원본 파일을 함께 점검한다. 제외된 프로젝트·업무 페이지는 빌드 시 이전 생성 파일도 정리한다. 소프트웨어의 필수 라이선스 고지는 유지한다.
