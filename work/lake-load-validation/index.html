적재 방식 구분과 원천·조회 건수 대조

전체 덮어쓰기, 파티션 덮어쓰기와 병합 갱신을 구분하고 적재 뒤 건수를 확인했습니다.

2024.03–2024.10 · 제조 데이터 레이크 고도화

배경

테이블마다 데이터가 바뀌는 방식이 달랐습니다. 적재 방식에 맞게 처리하고, 작업 종료 뒤 원천과 조회 결과의 건수를 별도로 확인했습니다.

한 일

  1. Airflow 수집과 S3 원본 보관, Glue·PySpark 정제, Parquet·Athena 조회 흐름에 참여했습니다.
  2. 전체 덮어쓰기, 파티션 덮어쓰기와 병합 갱신을 데이터 특성에 따라 구분했습니다.
  3. 원천 데이터와 조회 뷰의 건수를 비교하는 품질 확인과 모니터링 관련 작업을 기록했습니다.

결과

  • Airflow 작업 상태와 데이터 건수 대조 결과를 별도로 확인했습니다.

한 줄 요약

적재 방식별로 원천·조회 건수를 대조하며, 작업 성공 여부와 데이터가 맞게 들어왔는지는 따로 확인해야 한다는 걸 배웠습니다.

사용 기술

  • Airflow
  • S3
  • Glue
  • PySpark
  • Athena
