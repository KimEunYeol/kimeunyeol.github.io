모델별 전처리·추론 서비스 확장

외부 데이터를 연결하고 모델별 전처리·추론 컨테이너를 확장하는 작업에 참여했습니다.

2021–2023, 단계별 참여 · 제조 AI 운영 백엔드 구축·확장

배경

분석 모델을 추가하려면 데이터 수집, 전처리와 추론 결과 제공도 함께 이어져야 했습니다. 외부 원천 데이터 연계와 모델 서비스 확장 작업을 맡았습니다.

한 일

  1. SOAP 웹 서비스에서 데이터를 수집해 백엔드에 연결했습니다.
  2. 모델 운영정보와 모델별 전처리·추론 컨테이너를 추가하는 구조를 사용했습니다.
  3. Kafka 전달, Redis 추론용 데이터와 S3 이력 저장을 사용하는 백엔드에서 작업했습니다.

결과

  • AI 운영시스템 구축과 서비스 확산·확장 단계에 참여했습니다.
  • 모델별 처리 서비스와 공통 데이터 연계를 구분해 백엔드를 확장했습니다.

한 줄 요약

외부 데이터를 연결하고 모델별 전처리·추론 서비스를 확장하며, 공통 데이터 흐름과 모델별 처리를 나눠두는 이유를 체감했습니다.

사용 기술

  • Docker
  • SOAP
  • Kafka
  • Redis
  • S3
