NiFi·Hive 연결 오류와 CSV 전처리

CSV 형식 변경에 대응하고, 반복되는 Hive 연결 오류를 점검했습니다.

2023.01–2023.02 · 공공 재정 데이터 분석 플랫폼

배경

CSV를 HDFS·Hive로 전달하고 분석 서버로 내보내는 과정에서 파일 형식 변경과 Hive 연결 오류가 발생했습니다. 파일 전처리와 연결 설정을 나눠 확인했습니다.

한 일

  1. 구분자 변환과 헤더 대문자 변환 등 CSV 전처리를 추가했습니다.
  2. 단순 쿼리로 확인하고 연결 대기·연결 수 설정을 조정했지만 broken pipe가 반복되는 것을 기록했습니다.
  3. Hive 설정 파일을 추가한 뒤 다량의 FlowFile로 시험하고, 전체 배치의 로그를 별도로 확인했습니다.
  4. 테이블별 연결 서비스를 상위 범위의 공유 서비스로 묶는 방식과 실패 건의 재처리를 다뤘습니다.

결과

  • 구분자와 헤더 형식 변경은 전처리를 추가해 대응했습니다.
  • 연결 시험 뒤에도 전체 배치에서 일부 Hive → CSV 작업이 실패해 재처리가 필요했습니다.

한 줄 요약

CSV 전처리와 Hive 연결 오류를 다루면서, 작은 연결 시험을 통과해도 실제 전체 배치에서 다시 확인할 필요가 있었습니다.

사용 기술

  • NiFi
  • Hive
  • HDFS
  • CSV
