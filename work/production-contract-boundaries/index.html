파이프라인 실행과 품질 판정 나누기

명세, 실행, 품질 검사와 증거 이력을 연결하는 사내 플랫폼을 설계했습니다.

진행 중 / 2026.11 기준 · 데이터 생산 통제 플랫폼 개발

배경

실행이 성공해도 데이터 품질에 문제가 있거나 검사 근거가 빠질 수 있습니다. 실행 상태와 데이터의 사용 가능 여부를 별도로 관리하도록 구조를 나눴습니다.

한 일

  1. 파이프라인 실행 명세와 개발 요구사항 문서를 구분했습니다.
  2. 명세, 실행, 품질 판정과 증거 이력의 역할을 나눠 아키텍처를 설계했습니다.

결과

  • 제품 등록, 가상 데이터 모의 실행, 검사 결과와 이력 조회 기능을 로컬 MVP로 만들었습니다.
  • 실행 결과와 품질 판정을 별도로 저장하도록 구성했습니다.

덧붙이면

로컬 MVP 개발 단계입니다. 운영 DB와 스케줄러에는 아직 연결하지 않았습니다.

사용 기술

  • Python
  • FastAPI
  • Pydantic
  • 파이프라인 명세
