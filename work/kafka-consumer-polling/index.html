수집 지연과 Kafka Consumer Poll 점검

추론용 데이터가 늦게 도착하는 문제를 추적하며 Kafka Consumer의 Poll 동작을 점검했습니다.

AI 운영시스템 참여 기간 · 제조 AI 운영 백엔드 구축·확장

배경

추론에 사용할 데이터가 늦게 도착하는 문제가 있었습니다. 원천 수집, 메시지 전달과 소비 구간을 나눠 지연이 생기는 지점을 확인했습니다.

한 일

  1. CloudWatch의 자원 모니터링과 서버별 상세 로그를 확인했습니다.
  2. Kafka Consumer가 한 번에 과도한 메시지를 Poll하는 문제를 점검했습니다.

결과

  • 수집 지연을 조사하는 과정에서 Consumer Poll size 초과와 과다 Poll 문제를 확인했습니다.

덧붙이면

당시 확인한 Poll 문제를 정리했습니다. 설정 조정값과 개선 수치는 기재하지 않았습니다.

사용 기술

  • Kafka
  • SOAP
  • CloudWatch
  • Redis
