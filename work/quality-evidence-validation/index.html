품질 실패와 검사 증거 누락 테스트

가상 주문 데이터로 정상, 품질 실패와 증거 누락 시나리오를 검증했습니다.

2026.11, 로컬 MVP · 데이터 생산 통제 플랫폼 개발

배경

품질 검사에 통과했다는 값만 있고 근거가 없거나 다른 출력의 검사 결과를 참조하면 데이터를 사용 가능으로 처리할 수 없습니다. 이런 경우를 가상 주문 데이터로 테스트했습니다.

한 일

  1. 정상 실행, 품질 실패와 검사 증거 누락 시나리오를 만들었습니다.
  2. 제품, 실행, 출력과 검사 증거를 연결하고, 필수 검사 실패나 증거 부족 시 사용을 보류하도록 했습니다.
  3. 동일 요청 재시도, 입력 충돌, 저장 중 실패와 재시작 후 조회를 검증 대상으로 잡았습니다.

결과

  • 정상·품질 실패·증거 누락을 서로 다른 상태로 처리하도록 로컬 기능을 검증했습니다.
  • 제품과 출력에 맞는 검사 결과와 증거가 있을 때만 사용 가능 여부를 판정하도록 구성했습니다.

한 줄 요약

가상 데이터로 실패·증거 누락을 테스트하면서, 통과한 결과만큼 사용을 보류하는 이유도 남겨야 한다고 느꼈습니다.

사용 기술

  • FastAPI
  • Pydantic
  • SQLite
  • pytest
