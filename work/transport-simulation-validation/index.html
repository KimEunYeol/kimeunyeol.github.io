운송 실적 정제와 시뮬레이션 결과 비교

운송 실적을 정리하고 같은 물동량 조건에서 AS-IS와 TO-BE 결과를 비교했습니다.

2026.07 · 제조 물류 운송 최적화 시뮬레이션

배경

운송 실적에는 시간·차량 컬럼의 확인이 필요한 항목이 있었습니다. 입력 데이터를 정리하고 업무 제약과 단위 환산 기준을 맞춘 뒤 시뮬레이션을 테스트했습니다.

한 일

  1. 필수 입력 컬럼과 차량 용량·시간·거리 제약을 협의했습니다.
  2. 가상 데이터로 시뮬레이션 틀을 구성한 뒤 실제 운송 실적으로 테스트했습니다.
  3. 시간·차량 컬럼을 점검하고 정제 데이터와 제외 데이터를 구분했습니다.
  4. AS-IS와 TO-BE의 차량 수, 운행 횟수와 물동량을 대조했습니다.

결과

  • 시뮬레이션 입력·제약사항과 데이터 정리본을 공유했습니다.
  • 물동량 보존 여부와 차량·운행 횟수를 비교한 테스트 요약을 전달했습니다.

한 줄 요약

운송 실적을 정제하고 시뮬레이션을 비교해보니, 차량 수보다 먼저 입력 조건과 물동량이 같은지 확인하는 일이 중요했습니다.
